# Find Key Term

Find the key terms in section pages.

# Guidelines

- Search for text that is highlighted in green. Example: `<span class="mt-bgcolor-2ecc71">[term]</span>`
- The value for `[term]` is assigned based on the found html. Example: for `<span class="mt-bgcolor-2ecc71">black hole</span>` then `[term]` is `black hole`
