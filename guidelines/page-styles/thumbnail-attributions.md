# Style for Thumbnail Attributions

## Thumbnail Attribution Format

Only present in the introduction pages for chapters, located at the bottom. The attribution is for the thumbnail for the chapter. Since it is decorative, no accessible description is required. The main part of the text that needs to be formatted is the figure attribution, but check the rest of the text, making sure that Thumbnail is bold, there is a period after the thumbnail caption text, etc.

### Text Format

Thumbnail: Thumbnail caption text. (License[LicenseLink]; Author[AuthorLink] via Source[ImageLink])

#### Example Text

Thumbnail: The James Lick telescope at Lick Observatory, Mt. Hamilton, California. It is a 36 inch refractor. (CC BY 2.0; myyorgda via Wikimedia Commons)

### HTML Format

<p><strong>Thumbnail</strong>: Thumbnail caption text. (<a href="LicenseLink" target="_blank" title="License">License</a>; <a href="AuthorLink" target="_blank" title="Author">Author</a> via <a href="ImageLink" target="_blank" title="Source">Source</a>)</p>

### Attribution information

- All information needed to format the attribution should be present
- refer to `attribution-info.md` to decode shorthand for sources, licenses, and links
- if any needed information is not present, ask the user for help
