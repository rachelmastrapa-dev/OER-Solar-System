# Key Terms Link

The text that replaces the highlighted text in the local html files for each section page.
Refer to the variables section in `editing-standards.md` for variable definitions.

## Key Terms Link HTML Format


- The key terms link, `<key-terms-link>` is formatted: 

`<strong><a href="/Workbench/[TextbookTitle]/[NN]:_[ChapterTitle]/<N>.<KK>:_Key_Terms#<term-anchor>" target="_blank" title="<term-sing>">[term]</a></strong>` 

where 
`[NN]` = `<NN>`, and `[ChapterTitle]` = `<ChapterTitle>` with `-` replaced by `_`

## HTML Format


## Examples

 <strong><a href="/Workbench/DeAnza_-_ASTR4/01:_Introduction_to_Astronomy/1.06:_Key_Terms#theory" target="_blank" title="theory">theory</a></strong>
