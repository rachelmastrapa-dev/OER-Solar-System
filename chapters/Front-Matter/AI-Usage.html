Artificial Intelligence Disclosure

The paragraph text from this book is sourced from the OER attributed on each page, along with original contributions from the authors. Generative AI provided by LibreTexts was used to produce the page summaries. AI tools were used to proofread text and format citations, attributions, and figure properties such as captions, alt-text, and accessible descriptions using Playlab and Claude Code.

Playlab

Rachel created several tools in Playlab to assist with formatting citations, attributions, and key terms, none of which are user-friendly for anyone but her. After growing tired of copying and pasting text, she changed to agentic AI.

Claude Code

Inspired by a keynote by Joel Gladd at the 2026 CalOER conference, Rachel created a GitHub repository for this textbook and started building skills using Claude Code. The repository contains a copy of each page in the textbook in HTML with LaTeX for equations. It also includes the skills, session files, a documents directory with various resource files, and a guidelines directory with files defining editing standards.

Skills

With the assistance of Claude Code, Rachel made the first skill to efficiently remove any special formatting carried over from original sources. From there she designed an overall editing workflow and created a set of skills to do the following:

  • Create local copies of textbook pages in individual files.
  • Format page attributions including links to the original sources.
  • Format APA references.
  • Format figure HTML which includes:
    • Alternative text
    • Figure captions
    • Figure attributions
    • Accessible descriptions
  • Format the links for key terms in text and create the key terms page.
  • Complete a final review of spelling and grammar.

For all of these skills, Claude Code was provided information and edited the local files. For example, Claude was provided with information about a figure including any available alternative text, caption, or description. The main changes are reformatting information following the editing standards developed by Rachel and provided in the repository. These standards include many style files that define not only the HTML format, but also include ADA and IDEA recommendations. Based on these standards, Claude Code would make minor changes. If any changes involved an entire sentence or more, Claude Code was instructed to ask Rachel for guidance.

Safety and Record Keeping

Throughout the project, Rachel used Claude Code with training turned off, along with other privacy settings activated. She has not submitted any private information, such as authentication credentials, to Claude Code.

The advantage of using GitHub is that each commit can track the changes made by Claude Code and differentiate them from changes made by Rachel. It is also an opportunity for Rachel to review and approve each change. Rachel also had Claude Code record its actions in a daily session file, for redundancy. Each session file represents the work completed in a daily editing branch that is merged at the end of the day. This provides clear record keeping of human activity and supervision.
